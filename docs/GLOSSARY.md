# 术语表

| 术语 | 含义 |
|---|---|
| 拾星迹 | 正式中文产品名 |
| StarTrail | 仓库代号，非已承诺英文商标 |
| Vault | 用户控制的加密数据根目录 |
| VMK/KEK | Vault 主密钥 / 由密码派生的包装密钥 |
| 对象 | 不可变、认证加密的内容单元 |
| manifest | 加密的对象引用及版本头集合 |
| HEAD | 指向当前 manifest 的非语义化指针 |
| sibling | 同一实体的并发版本，须保留/解决 |
| tombstone | 表示删除的可同步对象 |
| R2 | Cloudflare 的 S3 兼容对象存储 |
| canonical JSON | 规范化、可重复编码的 JSON |
