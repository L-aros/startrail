# 验收测试

1. 离线创建 Vault，写入 100 条与附件，重启/锁定/解锁后完全可读。
2. 错误密码、修改任一密文字节、未知关键格式版本均不能泄露内容或写入。
3. 在写对象、更新 HEAD、同步上传各阶段强制终止，重启后 Vault 可打开且无已确认数据丢失。
4. 从加密备份恢复至干净设备，digest 一致；恢复失败不影响原 Vault。
5. 两设备离线编辑同条目后同步：显示冲突，双方版本保留，解决后收敛。
6. 断网、R2 412、磁盘满、取消同步均可重试，不产生明文远端对象。
7. Android 与 Windows 上完成键盘/读屏/系统字号关键路径。
8. 抓包、日志和 telemetry fixture 中无正文、凭据、密钥、对象 ID 或语义路径。
