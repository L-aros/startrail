# 威胁模型

| 资产/攻击者 | 风险 | 缓解 | 残余 |
|---|---|---|---|
| 丢失设备/本地攻击者 | 读取磁盘数据 | 强密码 KDF、VMK 加密、DB 加密、锁屏后清内存 | 已解锁设备、恶意 OS 不可完全防御 |
| R2/网络攻击者 | 读取/篡改/回滚对象 | E2EE、AEAD、TLS、HEAD 条件更新、版本/父链检查 | 可见大小、频率、IP；可拒绝服务 |
| 恶意同步设备 | 覆盖/注入内容 | 不可变对象、冲突保留、认证对象 | 持有 VMK 的设备可读写数据 |
| 恶意更新/依赖 | 执行任意代码 | 签名更新、锁定依赖、SBOM、审查、CI | 供应链零日风险 |
| 日志/遥测 | 内容外泄 | 最小事件、默认关闭、脱敏测试 | 用户主动附带的诊断材料 |

不解决：遗忘密码、受控/被攻破的 OS、截屏、物理键盘记录、R2 流量分析与合法强制访问。安全事件按 SECURITY.md 处理。
