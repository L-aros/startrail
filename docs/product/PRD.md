# PRD — 拾星迹 v1

## 问题与目标

用户需要长期、私密、可迁移地保存成长记录，而不应被账户锁定或云端明文所绑架。v1 让用户离线创建 Vault、记录条目、附加媒体、按时间浏览、加密备份/恢复，并可选同步自己的 R2。

## 用户故事与完成条件

| 故事 | 完成条件 |
|---|---|
| 创建私密空间 | 设置密码后生成 Vault；提示密码不可恢复；创建失败不留下半成品 |
| 记录片段 | 可创建、编辑、删除草稿/条目，含时间、正文、心情、标签、附件 |
| 回看足迹 | 时间线按事件时间倒序、按标签筛选；搜索仅在解锁后的本地索引 |
| 带走数据 | 可生成加密 Vault 备份、在另一设备验证并恢复；错误密码不改写现有 Vault |
| 同步自己的存储 | 显示同步范围、进度、冲突和最后成功状态；任何失败可重试且不丢本地写入 |

## 范围

Android 10+、Windows 10/11；单用户、单 Vault、多设备；图片、音频、任意附件；本地通知可后续加入。v1 不含账号、共享、协同编辑、AI 云处理、Web/iOS、服务端全文检索。

## 质量目标

- 无网时所有记录/阅读/搜索可用。
- 正常关机、崩溃或取消不能产生被接受但不可解密的对象。
- 错误密码、篡改密文或降级格式必须明确失败，不能静默返回内容。
- 可访问性：所有关键按钮有语义标签、键盘可达、系统字号可用。

## 发布门槛

满足 `docs/quality/ACCEPTANCE.md`；无 P0/P1 未解决安全问题；恢复和同步断点测试通过；隐私、第三方清单、更新签名与版本说明完成。
